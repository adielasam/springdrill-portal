Bulk Print Report Cards

One card per student for the whole class. Print (or save as PDF from the print dialog). Cards show approved & published results by default.

Database setup required. The results tables need the Phase 1 setup before cards can load. Ask the administrator to run supabase/migrations/phase1-results-engine.sql once in the Supabase SQL editor, then reload this page.
