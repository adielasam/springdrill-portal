Publish Reports

Publishing is the last step: only approved results can be published, and only published results appear on the student's report card. Publishing sends each affected student an in-portal message. Unpublish returns published results to approved so corrections can be made.

Database setup required. The results tables need the Phase 1 setup before publish status can load. Ask the administrator to run supabase/migrations/phase1-results-engine.sql once in the Supabase SQL editor, then reload this page.
